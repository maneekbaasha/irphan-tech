# Project cards QA checklist

## Desktop
- Primary Helpdesk card spans the full project width.
- Nginx and AI Support sit side by side at large breakpoints.
- irphan.eu is visually secondary.
- Text hierarchy remains category → title → description → stack → action.
- Hover motion stays subtle and does not shift surrounding layout.

## Tablet
- Cards stack cleanly below 1100px.
- Visual areas remain present without dominating the copy.
- Tool chips remain readable and do not overflow their card.

## Mobile
- Single-column layout.
- Action target remains at least 38px in the compact card UI.
- Tool chips can scroll horizontally without forcing the page wider.
- No meaning depends on hover.

## Accessibility
- Visible keyboard focus on every project link.
- Reduced-motion preference disables decorative reveal and press transforms.
- Light theme preserves card boundaries and stack separation.

## Content
- Technical labs remain the primary proof projects.
- irphan.eu remains contextual product work rather than a fourth equal technical lab.
