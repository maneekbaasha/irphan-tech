# Project cards redesign — UX/UI rationale

This pass intentionally separates utility from decoration.

## Hierarchy

1. Modern IT Helpdesk Lab is the primary proof project.
2. Nginx SOC Detection Lab and AI IT Support Lab are supporting technical proofs.
3. irphan.eu is contextual product work and remains visually secondary.

## Card grammar

Each technical card follows the same reading order:

- category / domain
- project title
- short outcome-oriented description
- tools / stack
- explicit action

## Visual direction

The visual system is Apple-inspired in rhythm rather than imitation: calm hierarchy, generous spacing, large focal areas, restrained color, and motion that reinforces focus.

The three technical cards keep distinct identities:

- Helpdesk: system / workstation / cloud management language
- Nginx: detection / routing / grid language
- AI Support: connected flow / assistance language

## Interaction

Hover motion is deliberately subtle. Press states are tactile but minimal. Touch layouts avoid hover-dependent meaning. `prefers-reduced-motion` disables decorative motion.

## Follow-up assets

The generated 1200×630 WebP images remain reserved for social/Open Graph previews. They can later replace or complement the abstract in-card visuals without changing the information architecture.
